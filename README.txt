JOB AND INTERNSHIP MANAGEMENT SYSTEM
PHP + MySQL + XAMPP

SETUP:
1. Copy this folder to C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql.
5. Open http://localhost/Job_Internship_Management_System/
6. Register a student account and login.
7. Admin panel: http://localhost/Job_Internship_Management_System/admin/
   Admin password: admin123

DATABASE:
Database name: job_internship_db
